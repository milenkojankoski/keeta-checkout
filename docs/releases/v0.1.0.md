Keeta Checkout 0.1.0, the first release. Accept Keeta payments on your website.

**What you get**

- A small server that watches your own Keeta account and marks orders paid. It holds no key: a compromise of the server cannot move your funds.
- A hosted pay page with a QR code and a `keeta://` link, working with JavaScript off.
- Signed webhooks, delivered at least once and retried for about a day.
- A WooCommerce plugin for the classic and the block checkout.
- A `<keeta-pay-button>` web component and a React wrapper.

**Install**

```
npx keeta-checkout init
npx keeta-checkout check
npx keeta-checkout serve
```

Or run the image: `ghcr.io/milenkojankoski/keeta-checkout:0.1.0`. The WooCommerce plugin is the zip attached below; upload it under Plugins, Add New.

Full walkthrough: [docs/quickstart.md](https://github.com/milenkojankoski/keeta-checkout/blob/v0.1.0/docs/quickstart.md).

**Know before you go live**

- Start on the test network. Switch to main only after a real payment has completed end to end on test.
- On main, Bivo's bare fiat tokens (`USD`, `EUR`, ...) are permit lists almost no shopper can hold. Price in `$USDC` or `$EURC`.
- There are no refunds yet. The server records every underpaid, late or duplicate payment and the plugin leaves a note on the order; send the money back by hand.
- Put a rate limit on the pay routes at your reverse proxy. The server bounds what it can but deliberately ships no limiter of its own.
- One server per database.
- Verified by security review twice, by two different reviewers; see `docs/decisions/0013-security-review.md`.
